### Consumer Service
This package provides scripts that will process message queues and send messages to customers on different channels, depending on message parameters, e.g SMS, Email, WhatsApp

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/CIC-INSURANCE-GROUP/smsservice.git
cd smsservice
```

### 2. Install dependencies
```bash
yarn install
```

### 3. Configure environment
Add a .env file with environment variables

### 4. Run servers
To locally run the consumer services run the following

```bash
npm start pm2:start-all
```
